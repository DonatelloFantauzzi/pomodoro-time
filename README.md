# 🍅 Pomodoro Timer

A modern, feature-rich Pomodoro Timer built with Vue 3 and Tailwind CSS.

## ✨ Features

- ⏱️ Customizable work/break durations
- 🔊 Sound alerts with volume control
- 🌙 Dark mode support
- 💾 Persistent settings (localStorage)
- 🎨 Smooth animations and transitions
- 📱 Responsive design
- ♿ Accessible UI

## 🚀 Tech Stack

- Vue 3 (Composition API)
- Tailwind CSS
- Web Audio API
- localStorage

## 🛠️ Installation
```bash
npm install
npm run dev
```
